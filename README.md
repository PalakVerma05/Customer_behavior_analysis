# Customer_behavior_analysis
Data Analytics Project using Python, SQL &amp; Power BI for Customer Behavior Analysis and Interactive Dashboard Visualization.

# 📊 Data Analytics Project

## 📌 Overview

This project demonstrates an end-to-end **Data Analytics workflow** using Python, SQL, and Power BI.
The goal of the project is to collect, clean, analyze, and visualize data to generate meaningful business insights.

The project covers:

* Loading and processing datasets in Python
* Performing Exploratory Data Analysis (EDA)
* Cleaning and transforming data
* Writing SQL queries for analysis
* Creating interactive Power BI dashboards
* Preparing a final analytical report and presentation

---

## 📂 Dataset

The dataset used in this project contains structured data related to business/customer/sales operations.
It was imported into Python for preprocessing and later stored in SQL databases for querying and analysis.

### Dataset Features

* Multiple columns with numerical and categorical data
* Missing values and duplicate records
* Business metrics for trend analysis and visualization

## 🔄 Project Workflow

### 1. Data Loading

* Imported CSV/Excel datasets into Python using Pandas
* Checked dataset structure and basic statistics

### 2. Exploratory Data Analysis (EDA)

* Analyzed trends, patterns, and distributions
* Identified missing values and outliers
* Created visualizations for better understanding

### 3. Data Cleaning

* Removed duplicates
* Handled missing values

### 4. SQL Analysis

  * Filtering data

  * Business KPI analysis

### 5. Dashboard Creation

* Built interactive dashboards in Power BI
* Added charts, KPIs, slicers, and filters
* Designed dashboards for easy business insights

### 6. Reporting & Presentation

* Created a detailed analytical report
* Prepared a professional PPT presentation using Gamma AI

## 🚀 How to Run the Project

### Step 1: Clone the Repository

```bash
git clone <repository-link>
```

### Step 2: Install Required Libraries

```bash
pip install pandas numpy matplotlib seaborn
```

### Step 3: Run Jupyter Notebook

```bash
jupyter notebook
```

### Step 4: Open the Project Files

* Run Python notebooks for EDA and preprocessing
* Execute SQL scripts in PostgreSQL/MySQL/SQL Server
* Open the `.pbix` file in Power BI Desktop
